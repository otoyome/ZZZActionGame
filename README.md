ステージとリザルト絵は借り物ですが、他はほぼ自作のリソースを使っています。  

〇ゲームの趣旨
　プレイヤーとボスの1vs1
　HPを減らすのが基本的な内容ですが、
　攻撃・又はパリィでボスの体幹にダメージを与えて、
　最大まで与えたらブレイク状態に入ります。
　その際強力な一撃を与えられ、その後スタッガー状態に入ります。
　この間無防備なため、攻撃し続けることが出来ます。

〇操作方法
　WASD：キャラクターを動かします
　マウス：カメラ操作
　左クリック：攻撃
　右クリック：回避(ジャスト回避もあります)
　Eボタン：特殊技
　スペース：パリィボタン

〇バグ・調整不足な点
　二ヶ月でフルスクラッチを決めて実装したのでいくつか問題点があります。
　・パリィ
　　かなり受付を長くしてしまった。
　・ボスのAI
　　発狂状態のパリィ演出中に普通に動いてしまうことがある
　・モーション類の調整不足
　　特にブレイク時の攻撃、特殊技でモーションそのものがかなり微妙
　・ボスを倒した時の演出
　　スピード感が微妙になってしまっており、倒した爽快感がかなり減っている
